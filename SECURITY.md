# Security Policy

## Supported Versions
Security updates are provided for the latest released version of XChange only.

| Version | Supported |
|----------|------------|
| 5.2.x    | ✅ Active  |
| < 5.2    | ❌ No longer supported |

## Reporting a Vulnerability
If you discover a security vulnerability in XChange:

1. **Do not open a public issue.**
2. Email the core maintainers at [security@knowm.org](mailto:security@knowm.org).
3. Include detailed steps to reproduce the issue, affected modules, and potential impact.
4. You will receive a response within 72 hours.

Responsible disclosure is appreciated. Thank you for helping us keep XChange secure.
